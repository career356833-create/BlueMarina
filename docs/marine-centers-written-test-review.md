## 앱 반영 준비 가능 여부

조건부 가능입니다.

현재 CSV는 공식 자료 기반 필드 수집이 완료되어 1차 입력 후보로 사용할 수 있습니다. 다만 다음 보완 후 앱 반영을 권장합니다.

1. 요청 수량 32개와 공식 확인 수량 31개의 차이 재검증
2. `availableLicenses` 공식 확인
3. 경북(안동) 중복 주소 병합 정책 결정
4. 상설PC/특별 시험장 구분을 `note`로 유지할지 별도 필드로 분리할지 결정
