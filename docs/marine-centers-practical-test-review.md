## 앱 반영 준비 가능 여부

조건부 가능입니다.

현재 CSV는 공식 자료 기반 필드가 모두 채워져 있어 1차 반영 후보로 사용할 수 있습니다. 다만 실제 앱 반영 전 다음 사항을 결정해야 합니다.

1. 일반/요트 같은 주소 중복 2건을 병합할지 별도 행으로 유지할지 결정
2. `availableLicenses`를 시험장별 응시가능 시험 안내 또는 접수 화면과 교차 확인
3. 실기시험장 목록의 현재 운영 상태를 일정 조회 화면으로 보조 확인
4. 향후 지도 연동 전 주소 정규화 및 좌표 수집
