# Blue Marina Next Priority Roadmap V2

**[NEXT PRIMARY PRIORITY] `VERIFIED_CHARTER_SUPPLY_AND_INQUIRY_LAUNCH`**

우선순위 1은 **이번 감사에서 실행하지 않는다.** 본 감사의 업체 연락·DB 적용·배포·feature flag 변경은 모두 0이다. 2·3은 공급자 동의 및 관리자 승인 없이 진행할 수 없다. 4는 실기기 접근 전까지 완료로 표시하지 않는다.

당분간 추가 KMA/KHOA/NIFS 소스 하나 더 조사하기, 이미 1,258종 정규화된 canonical의 경미한 잔여 예외에 장시간 투자하기, 공급 없는 Market/Community UI를 확장하기, 실제 기기 검증 없는 HUD polish는 보류한다. 이미 쌓인 MBRIS·로그·실험 작업 트리는 버리지 않고 별도 소유자와 보존/정리 범위를 정한다. 이 판단은 해당 작업의 기술적 가치가 없다는 뜻이 아니라, **현재 공급·문의 전환 병목보다 낮은 우선순위**라는 뜻이다.
