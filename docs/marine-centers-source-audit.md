# Blue Marina 전국 시험장·교육장 데이터 수집 사전 감사

작성일: 2026-06-19

## 목적

`/centers`에 실제 시험장·교육장 데이터를 입력하기 전에 공식 출처, 수집 가능 필드, 지역별 규모, 중복 위험, `sourceUrl` 운영 전략을 정리합니다.

이번 문서는 사전 감사 문서이며 실제 시설 데이터는 입력하지 않습니다. 앱 코드, 샘플 데이터, 외부 링크 연결도 변경하지 않습니다.

## 공식 출처 후보

### 1. 해양경찰청 수상레저종합정보 메인 빠른찾기

- 성격: 시설 종류별 전국 목록을 빠르게 확인할 수 있는 1차 출처
- 확인 가능한 항목:
  - 조종면허 필기시험장
  - 조종면허 실기시험장
  - 수상안전교육장
  - 면제교육장
- 장점:
  - 시설 종류와 면허 종류가 한 화면에서 구분됩니다.
  - 일반조종, 요트조종 구분이 목록 구조에 드러납니다.
- 한계:
  - 주소와 전화번호가 함께 표시되지 않는 항목이 있습니다.
  - 시설명 중복, 지역명 축약, 요트/일반 명칭 혼재가 있어 상세 페이지 교차 확인이 필요합니다.

### 2. 해양경찰청 수상레저종합정보 전국 시험장 안내

- 성격: 필기시험장, 실기시험장, 면제교육기관 상세 수집의 우선 출처
- 확인 가능한 항목:
  - 시설명
  - 주소
  - 전화번호
  - 위치보기 구조
  - 필기 상설PC 시험장
  - 필기 특별 시험장
  - 실기시험장
  - 면제교육기관
- 장점:
  - 주소와 전화번호가 시설별로 표시됩니다.
  - 탭 또는 섹션 기준으로 시설 종류를 구분할 수 있습니다.
- 한계:
  - 같은 장소가 일반/요트 또는 시험장/교육기관으로 중복 등장할 수 있습니다.
  - 위치보기는 지도 연동 후보이지만 이번 단계에서는 좌표를 수집하지 않습니다.

### 3. 해양경찰청 수상레저종합정보 전국 교육장 안내

- 성격: 수상안전교육장 상세 수집의 우선 출처
- 확인 가능한 항목:
  - 교육장명
  - 주소
  - 전화번호
  - 지역 선택 구조
  - 위치보기 구조
- 장점:
  - 교육장별 주소와 전화번호를 직접 확인할 수 있습니다.
- 한계:
  - 메인 빠른찾기의 수상안전교육장 목록과 상세 교육장 안내 목록의 표기 수가 일부 다르게 읽힐 수 있습니다.
  - 정식 수집 시 두 출처를 교차 확인해야 합니다.

### 4. 시험 일정 조회 / 교육 일정 조회

- 성격: 시설 활성 여부와 현재 접수 가능성 확인용 보조 출처
- 확인 가능한 항목:
  - 시험 과목
  - 시험장 선택 구조
  - 날짜 선택 구조
  - 접수 가능 여부
- 수집 전략:
  - 시설 마스터 데이터의 원천으로 고정하지 않습니다.
  - `status` 보정 또는 운영 여부 확인의 보조 자료로만 사용합니다.
  - 일정, 접수 가능 인원, 결제 방식 등 변동성 높은 값은 `/centers` 시설 데이터에 고정 입력하지 않습니다.

## 중복 가능성

1. 같은 장소가 여러 역할을 가질 수 있습니다.
   - 예: 실기시험장, 수상안전교육장, 면제교육기관이 같은 주소를 공유할 수 있습니다.

2. 일반조종과 요트조종이 같은 기관명 또는 같은 주소로 분리 표기될 수 있습니다.
   - 데이터 모델에서는 한 시설에 `availableLicenses: ["general", "yacht"]`를 부여할지, 시설 역할별로 별도 행을 둘지 결정해야 합니다.

3. 시설명 표기가 출처마다 다를 수 있습니다.
   - 예: `서울요트`, `서울요트(마포)`, `서울요트(서초)`처럼 괄호 표기가 달라질 수 있습니다.

4. 주소와 전화번호가 출처별로 다를 수 있습니다.
   - 상세 페이지의 주소/전화번호를 우선하고, 메인 빠른찾기는 목록 확인용으로 사용합니다.

5. 같은 주소에 다른 전화번호가 존재할 수 있습니다.
   - 기관 대표번호, 시험 접수 번호, 교육장 번호가 분리될 수 있으므로 `note`에 확인 필요 사유를 남깁니다.

6. 지역 분류가 행정구역과 운영 권역 기준으로 섞일 수 있습니다.
   - 예: `충청`, `전라`, `경상` 같은 권역 표기는 CSV 입력 시 `region`을 광역 지자체 기준으로 정규화합니다.

## sourceUrl 전략

1. `sourceUrl`은 시설별 상세 확인에 사용한 공식 페이지를 기록합니다.
2. 메인 빠른찾기만 보고 입력하지 않고, 전국 시험장 안내 또는 전국 교육장 안내의 상세 주소/전화번호를 우선합니다.
3. 시험 일정 조회와 교육 일정 조회는 `status` 확인 보조 출처로만 사용합니다.
4. 지도 `위치보기` 링크는 이번 단계에서 `sourceUrl`로 사용하지 않습니다.
5. 외부 블로그, 카페, 커뮤니티, 시험장 사설 안내 페이지는 1차 sourceUrl로 사용하지 않습니다.
6. 공식 페이지 내 데이터가 서로 다르면 `status: unknown`으로 두고 `note`에 교차 검증 필요를 기록합니다.
7. `sourceCheckedAt`은 수집자가 실제 확인한 날짜를 반드시 입력합니다.

## 수집 우선순위

### 1순위: 필기시험장

- 이유:
  - 시설 수가 비교적 명확합니다.
  - 주소/전화번호가 전국 시험장 안내에 정리되어 있습니다.
  - 사용자 검색 수요가 높고, `/centers` 필터 검증에 적합합니다.
- 수집 순서:
  1. 상설PC 시험장
  2. 특별 시험장
  3. 지역명 정규화
  4. 주소/전화번호 검증

### 2순위: 실기시험장

- 이유:
  - 일반/요트 가능 여부가 서비스 핵심 필터와 직접 연결됩니다.
  - 실기학습 센터와 포털 연결성이 높습니다.
- 수집 순서:
  1. 일반조종면허 실기시험장
  2. 요트조종면허 실기시험장
  3. 동일 주소 중복 병합 여부 판단

### 3순위: 수상안전교육장

- 이유:
  - 면허 발급 전 단계에서 사용자 수요가 높습니다.
  - 전국 교육장 안내에 주소/전화번호가 존재합니다.
- 주의:
  - 메인 빠른찾기와 상세 교육장 안내 간 개수 차이를 재검증해야 합니다.

### 4순위: 면제교육기관

- 이유:
  - 일반/요트 면제교육기관이 분리되어 있고 중복 가능성이 큽니다.
  - 교육기관 명칭과 주소가 복잡해 수동 검수 비중이 높습니다.
- 수집 순서:
  1. 일반조종면허 면제교육장
  2. 요트 면제교육장
  3. 같은 주소/전화번호 중복 정리
  4. `availableLicenses` 병합 여부 판단

## 다음 작업 제안

1. `work/marine-centers-template.csv`를 복사해 실제 수집용 작업 CSV를 별도로 만듭니다.
2. 필기시험장 32개 후보부터 공식 상세 페이지 기준으로 입력합니다.
3. 필기시험장 입력 후 중복 ID, 빈 주소, 빈 전화번호, sourceCheckedAt 누락을 검증합니다.
4. 그 다음 실기시험장, 수상안전교육장, 면제교육기관 순서로 확장합니다.
5. 좌표와 지도 API는 모든 공식 주소 입력이 끝난 뒤 별도 작업으로 분리합니다.
