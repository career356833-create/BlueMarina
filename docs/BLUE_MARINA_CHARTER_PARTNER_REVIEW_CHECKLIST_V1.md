# 출조업체 파일럿 관리자 검토 체크리스트

각 항목은 제출 자료와 출처 URL을 함께 기록합니다. 미확인 값은 `UNKNOWN`으로 남기고 승인 근거로 사용하지 않습니다.

| 검토 항목 | 확인할 것 |
| --- | --- |
| 업체명·신원 | 제출 주체와 업체의 관계, 상호 일치 여부 |
| 전화·이메일 | 공개 범위에 대한 공급자 확인과 실제 문의 경로 |
| 웹사이트·예약 링크 | HTTP(S), 공식 운영 주체, 해당 상품과의 관계 |
| 선박 | 선박명·정원·등록 근거; 동명 선박 충돌 |
| 출항항 | 항명·지역·실제 출항 관계; 지명 일치만으로 확정하지 않음 |
| 상품 | 상품명·운영 주체·현재 제공 여부 |
| 대상어종 | 정확한 canonical/승인 alias 또는 미해결 표시 |
| 가격 | 숫자·단위·적용 조건의 출처; 미확인 값은 null |
| 일정·좌석 | 현재 일정의 근거; 확인되지 않은 실시간 좌석 미표시 |
| MOF crosswalk | EXACT/HIGH/CANDIDATE/NO_MATCH와 수동 검토; 자동 인증 금지 |
| 중복·충돌 | 기존 등록과 중복, 상호·선박·항·상품의 중요 충돌 0인지 |
| 출처·공개 동의 | 공급자 제출 또는 명시 승인, URL·날짜, 연락처 공개 동의 |
| 최종 판정 | REQUEST_CHANGES / REJECT / APPROVE 및 검토자·근거 |

공개 후보 최소 조건은 **공급자 제출 또는 명시적 승인 + 확인 가능한 출처 + 명확한 업체 신원 + 공개 가능한 문의/예약 경로 + 중요 충돌 0 + 관리자 검토**입니다. `APPROVED`는 promotion candidate를 만들 수 있을 뿐 Production registry에 자동 게시되지 않습니다. 현재 서버에는 별도의 동의 이력 필드가 없으므로 공급자 승인 증빙이 없으면 게시 판단을 보류합니다.
