## 병합 정책이 필요한 사례

1. 같은 주소의 일반/요트 면제교육기관
   - 예: 서울서초(반포) / 서울요트(서초)
   - 후보 처리: 하나의 시설로 병합하고 `availableLicenses: general|yacht` 적용 가능

2. 같은 주소지만 `type`이 다른 시설
   - 예: 실기시험장과 면제교육기관이 같은 주소
   - 후보 처리: `type`이 다르므로 별도 행 유지 권장

3. 주소 표기가 공식 자료 안에서도 다르게 쓰이는 경우
   - 예: 경남(마산) 주소가 수상안전교육장 CSV와 면제교육기관 CSV에서 다르게 표시됨
   - 후보 처리: 공식 원문 유지 후 주소 정규화 단계에서 재검증

4. 행정구역 표기가 과거/현재 명칭과 섞인 경우
   - 예: `경상남도 마산시` 표기
   - 후보 처리: 공식 원문은 보존하고, 별도 정규화 필드를 도입할지 검토

## 앱 반영 준비 가능 여부

조건부 가능입니다.

현재 CSV는 공식 자료 기반 필드가 모두 채워져 있어 1차 반영 후보로 사용할 수 있습니다. 다만 실제 앱 반영 전 다음 사항을 결정해야 합니다.

1. 일반/요트 같은 주소 중복 8건을 병합할지 별도 행으로 유지할지 결정
2. 기존 필기/실기/교육장 CSV와 주소 중복이 많은 점을 고려해 `type`별 별도 행 유지 정책 확정
3. 주소 표기 정규화 정책 확정
4. 시험면제 신청 화면과 `availableLicenses` 교차 확인
5. 지도 좌표 수집 전 주소 원문과 정규화 주소를 분리할지 결정
