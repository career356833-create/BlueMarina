# Blue Marina 출조거점 공식 데이터 감사 1차

작성일: 2026-07-11

## 목적

Blue Marina의 출조거점 센터를 구축하기 전에 공식 출처에서 확보 가능한 데이터를 분리한다. 이번 감사는 앱 반영 전 조사이며, 실제 출조 가능 여부를 단정하지 않는다.

## 1차 결론

출조거점 기능은 공식 데이터 기반으로 1차 구축 가능하다. 다만 데이터 성격이 서로 다르므로 하나의 데이터로 합치기보다 다음처럼 나눠야 한다.

- 포인트 데이터: 갯바위낚시포인트, 선상낚시포인트, 바다낚시지수 포인트
- 시설 데이터: 소형선항만안내, 항만/어항/선착장 관련 데이터
- 사업자 데이터: 낚시산업정보, 낚시어선업 신고정보
- 안전/운영 데이터: 낚시어선 안전성 검사, 공동영업구역, 낚시터 정보

## 데이터별 세부 판단

### 해양수산부 공동활용체계 선상낚시포인트

- 전체 행: 329개로 확인
- 제공 형태: CSV, XML, JSON
- 주요 필드: 공간정보일련번호, 공간정보, 포인트명, 수심범위, 조수물때, 낚시방법/대상, 위도, 경도, 고시내용, 행정구역명
- Blue Marina 용도:
  - 선상낚시 포인트 목록
  - 지역/어종/수심/물때 필터
  - 지도 마커 후보
- 주의:
  - 포인트 데이터이지 선사 예약 데이터가 아님
  - 출조 가능 여부, 금지구역 여부, 실시간 통제는 별도 확인 필요

### 해양수산부 공동활용체계 갯바위낚시포인트

- 전체 행: 1076개로 확인
- 제공 형태: CSV, XML, JSON
- Blue Marina 용도:
  - 갯바위 포인트 목록
  - 지역별 포인트 탐색
  - 향후 안전 배지와 결합
- 주의:
  - 갯바위는 사고 위험이 높아 “낚시 가능” 단정 금지
  - 출입 통제, 사유지, 군사구역, 기상통제 여부는 별도 검증 필요

### 국립해양조사원 바다낚시지수 조회

- 제공 형태: OpenAPI
- 주요 내용: 포인트 위치, 날짜, 시간대, 물때, 파고, 수온, 유속, 어종별 낚시지수/점수
- Blue Marina 용도:
  - 오늘의 바다
  - 포인트별 출조 참고 지수
  - 어종별 추천도
- 주의:
  - API 키 필요
  - 실시간 안전 판단 대체 불가
  - Blue Marina에서는 “참고 지수”로 표시해야 함

### 낚시누리

- 운영: 해양수산부, 한국어촌어항공단 계열 낚시정보 종합 포털
- Blue Marina 용도:
  - 공식 안내 링크
  - 낚시어선 교육/공지 확인
  - 낚시산업 정보 검증
- 주의:
  - 직접 크롤링보다 공식 링크/사용 가능한 공개 데이터 우선

### 소형선항만안내

- 주요 필드: 행정구역명, 항만명, 위도, 경도, 소개설명, 항해정보, 항만설명
- Blue Marina 용도:
  - 항구/선착장/보트 출항 거점 후보
  - 지도 기반 시설 참고
- 주의:
  - 항만 안내 데이터이지 낚시 허용 데이터가 아님

### 낚시산업정보

- 주요 내용: 협회/기관/단체, 조구업체, 미디어, 판매점, 출조점, 정보제공업 등 사업자 정보
- Blue Marina 용도:
  - 출조점/낚시점/관련 업체 후보
  - Marketplace 또는 출조거점 보조 정보
- 주의:
  - 영업 여부와 최신 연락처 검증 필요

### 낚시 어선업 신고정보

- 주요 내용: 어선 일련번호, 어선 명칭, 총톤수, 선적항, 최대 승선인원수, 인허가 번호, 유효기간 등
- Blue Marina 용도:
  - 선사/낚시어선 후보 데이터
  - 선박 기본 정보 확인
- 주의:
  - 예약 가능 여부, 영업 상태, 선사 연락처는 별도 검증 필요
  - 개인정보/사업자 정보 노출 정책 검토 필요

## 앱 표시 정책

출조거점은 사용자 안전과 직결되므로 아래 배지를 기본 적용한다.

- 공식 데이터: 공공데이터 또는 공식 포털 출처가 확인된 항목
- 출조 가능 확인 필요: 낚시 가능 여부가 별도 검증되지 않은 항목
- 안전 확인 필요: 갯바위, 테트라포드, 방파제 등 사고 위험이 있는 항목
- 실시간 통제 확인: 기상, 공사, 항만 보안, 군사구역 가능성이 있는 항목

앱 문구 원칙:

- “낚시 가능”이라고 단정하지 않는다.
- “출조 전 공식 안내와 현장 통제를 확인하세요.”를 기본 문구로 둔다.
- 바다낚시지수는 “출조 참고 지수”로만 표기한다.

## 다음 절차

### Step 1. CSV 원본 확보

- 선상낚시포인트 CSV 다운로드
- 갯바위낚시포인트 CSV 다운로드
- 소형선항만안내 CSV 다운로드
- 낚시산업정보 CSV 다운로드
- 낚시어선업 신고정보 API/CSV 구조 확인

### Step 2. 정규화 템플릿 생성

`work/fishing-spots-template.csv` 기준 필드:

- id
- name
- type
- region
- city
- address
- lat
- lng
- targetFish
- tideNote
- depthNote
- methodNote
- safetyStatus
- sourceType
- sourceUrl

### Step 3. 1차 병합

- 선상낚시포인트: `boat-fishing-point`
- 갯바위낚시포인트: `rock`
- 소형선항만안내: `port` 또는 `pier`
- 낚시산업정보: `fishing-store`
- 낚시어선업 신고정보: `fishing-vessel`

### Step 4. 위험 배지 자동 부여

- 갯바위: 기본 `safetyStatus = needs-check`
- 항만/항구: 기본 `restricted-possible`
- 선상포인트: 기본 `needs-check`
- 공식 낚시터 또는 사업자: 출처 확인 시 `verified`

### Step 5. 앱 반영 전 감사

- 총 행 수
- type별 개수
- region별 개수
- lat/lng 누락 수
- 중복 좌표/중복 이름
- sourceUrl 누락
- safetyStatus 누락

### Step 6. 앱 1차 반영

- `/fishing-spots` 또는 출조거점센터 페이지 생성
- 검색/지역/type/어종 필터
- 지도는 placeholder 유지
- “공식 확인 필요” 배지 기본 노출

## 반영 가능성

조건부 가능.

공식 데이터는 충분하지만 “출조 가능 여부”와 “실시간 안전 상태”는 데이터만으로 확정할 수 없다. 따라서 Blue Marina는 출조거점 데이터를 정보 탐색용으로 제공하고, 실제 출조 판단은 공식 안내와 현장 통제 확인을 전제로 해야 한다.
