# Blue Marina 필기시험장 1차 샘플 수집 검토

작성일: 2026-06-19

## 목적

`/centers` 실제 데이터 반영 전에 필기시험장 후보 5개를 공식 자료 기준으로 샘플 수집했습니다.

이번 작업은 검토용 샘플 CSV 생성이 목적이며 앱 데이터 파일에는 반영하지 않았습니다.

## 공식 출처

- 출처명: 해양경찰청 수상레저종합정보 전국 면허시험장 안내
- 확인 영역: 필기(상설PC)시험장 목록
- sourceUrl: `https://boat.kcg.go.kr/home/custCnter/ntcInfo/infoView4.do`
- 확인일: 2026-06-19

## 생성 파일

- `work/marine-centers-sample-written-test.csv`

## 수집 기준

- 공식 페이지에 표시된 시설명, 주소, 전화번호만 입력했습니다.
- `type`은 모두 `written-test`로 입력했습니다.
- `sourceCheckedAt`은 2026-06-19로 입력했습니다.
- `sourceUrl`은 공식 전국 면허시험장 안내 페이지로 통일했습니다.
- 일반조종면허/요트조종면허 가능 여부는 해당 목록만으로 단정하지 않고 `availableLicenses`를 비워두었습니다.
- 주소에 쉼표가 포함된 행은 CSV 규칙에 따라 따옴표로 감쌌습니다.

## 앱 반영 가능 여부

현재 CSV는 1차 샘플로는 사용 가능합니다.

다만 앱 데이터에 반영하기 전에는 다음 확인이 필요합니다.

1. `availableLicenses`를 공식 자료로 추가 확인
2. 같은 시설이 다른 목록 또는 일정 조회 화면에서 동일하게 표시되는지 교차 확인
3. `status: active`가 현재 공식 목록 등재 기준으로 충분한지 운영 정책 확정
4. 전체 필기시험장 후보에 대해 동일한 규칙 적용

## 검토 결론

5개 샘플은 공식 페이지에 표시된 시설명, 주소, 전화번호 기준으로 수집되었습니다.

앱 반영은 가능하지만, `availableLicenses` 필드가 비어 있으므로 실제 서비스 데이터로 반영하기 전 면허별 응시 가능 여부를 추가 검증하는 것이 안전합니다.
