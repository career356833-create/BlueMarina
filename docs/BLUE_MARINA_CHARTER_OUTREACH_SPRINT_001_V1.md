## 연락 방식과 첫 제안

20곳 모두 공식 페이지 또는 기존 공식 연구 기록의 예약 전화가 있어 첫 연락 선호 경로를 `PHONE`으로 두었다. SMS·이메일·문의 양식·DM의 **우선 연락 대상 수는 0**이며, 실제 발송은 0이다. 개인 대표자 이름이나 개인 번호를 추정하지 않았다. 예약 전화의 제휴 문의 적합성은 통화 시작에 정중히 확인한다. 출조로 바쁜 시간, 야간, 휴무일을 피하고 업체가 원치 않으면 즉시 중단한다.

핵심 제안은 업체가 확인·제출한 출조상품 정보를 Blue Marina 파일럿에 소개하고, 고객을 기존 전화 또는 공식 예약 페이지로 연결하는 것이다. 업체와 관리자 승인 전 게시하지 않는다. 가격·일정은 업체가 변경을 요청할 수 있고, 실시간 잔여석·예약 확정·매출 증가를 약속하지 않는다. **등록 비용 정책이 아직 확정되지 않았으므로 ‘무료’라고 약속하지 않는다.** 비용이 실제로 0원으로 승인되면 문안을 다시 확인한 뒤 무료 파일럿 CTA를 사용할 수 있다. 당장 사용할 CTA는 “업체가 확인한 상품 정보를 파일럿 등록 대상으로 검토해도 괜찮으실까요?”이다.

동의 후 선택지는 기존 [직접 등록](/charters/onboarding), [CSV 템플릿](/charters/partners/template.csv), 또는 **별도 명시적 허가를 받은** 공식 홈페이지 정보 활용이다. 실제 제출에는 환경별 backend 제한이 있을 수 있다. `PUBLIC_INFO_REUSE_APPROVED`는 모두 `PENDING`; 구두 동의를 받더라도 범위와 시각을 tracker에 기록하고 관리자 검토 전 공개하지 않는다. 현재 서버 동의 이력 저장이 완성되지 않았으므로 별도 증빙이 필요하다.

**이메일 제목 3개:** “Blue Marina 출조상품 파일럿 등록 문의” / “공식 예약 경로를 유지하는 출조상품 소개 제안” / “출조업체 상품 정보 확인 및 제휴 안내 요청”

**‘자료 보내주세요’ 답변:** “제휴 1페이지 안내, [제출 가이드](BLUE_MARINA_CHARTER_PARTNER_SUBMISSION_GUIDE_V1.md), [CSV 템플릿](/charters/partners/template.csv)을 보내드리겠습니다. 받을 공식 이메일/채널을 알려주시겠습니까? 안내 발송도 동의하신 채널에 한 번만 하겠습니다.”
