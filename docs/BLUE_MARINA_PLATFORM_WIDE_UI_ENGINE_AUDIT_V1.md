## 홈 및 서비스 연결

- 데스크톱 홈의 이동 링크 21개와 모바일 20개를 개별 클릭했다. 반복 노출된 서비스 카드·메뉴, 도움말, 같은 화면의 서비스 섹션 이동을 포함한다. 모바일 하단 메뉴와 헤더·카드의 중복은 각 위치의 탐색 기능을 유지한다.
- 공개 47개 모두 390·1280px에서 실제 홈 링크를 눌러 `/`로 복귀했다. 사업 상세 3개는 항목 부재 안내에서 검증했다. 관리자 익명 404는 홈 복귀 집계에서 제외했다.
- 낚시 포인트 상세·Conditions·항법은 포인트 ID, 종 ID, 출처 및 내부 복귀 경로를 각 단계에서 사용한다. 항법 링크에는 대상 좌표, 이름 및 sourceId를 전달한다. 어종으로 위치나 안전항로를 추정하지 않는다.
- 상세 화면에서 목록으로, 학습 면허의 목록에서 상세·연습으로 돌아갈 수 있다. 출조 상품이 없는 경우에도 예약·문의 안내를 볼 수 있다.

## 지도와 장치

Production 모바일에서 Kakao SDK가 부분 초기화된 시점에 `LatLng is not a constructor`로 화면이 중단되는 것을 재현했다. Preview에서는 SDK를 그릴 수 있을 때까지 대기하며, 공급자 연결이 실패해도 바다 화면의 다른 기능과 홈 이동을 사용할 수 있었다. 실제 Kakao 영상 표시 성공은 등록 도메인에서 추가 확인해야 한다.

V5 항법은 포인트 복귀와 홈을 나눠 표시한다. 모의 GPS 현재 위치로 이동, Follow·항적 표시 전환, 2D↔3D 왕복, 항해 상세 열기를 Chrome에서 확인했다. 실측 SOG, 현장 항적 기록·복원, 실기기 GPS 권한과 잠금 후 복귀는 이번 브라우저 결과에 포함하지 않았다. V6 `3140724`의 Cesium/VWorld/DEM 경로는 별도 개발 브랜치다. 통합 시 공통 MarineNavigation의 목적지, Home/이전, 단일 위치 구독, 항해 세션 보존 계약을 다시 검증해야 한다. V6 브라우저 렌더링은 이번 변경의 인증 대상이 아니다.

## 남은 제한과 출시 판단

인증된 사용자·관리자 후속 화면, 실제 모바일 키보드·보조기기·GPS, 실항해는 확인되지 않았다. 일부 비어 있는 사업 상세는 프레임워크 스트리밍으로 HTTP 200에서 없음 안내를 표시한다. Charter의 CSV 파일 선택만 바뀐 경우와 모든 브라우저의 뒤로가기 동작까지 폼 이탈 시험을 확장해야 한다. 미발행 항목·비공개 콘텐츠를 만들어 빈 상태를 채우지 않았다. 다음 검증은 허용 도메인의 모바일 Kakao 지도와 소유자 계정의 작성·복귀 여정이다.

항법 홈 버튼은 390·1280px 모두 44×44 CSS 픽셀로 확인했다. 중앙 지점의 클릭 대상이 버튼 자체였고 이전 버튼과 겹치지 않았으며 키보드 Tab으로 도달했다. Charter·Market·Community의 없는 ID 화면에서 각 부모 목록으로 이동하는 CTA도 최종 Preview에서 각각 클릭했다.

최종 회귀 결과는 1,449개 통과, 2개 건너뜀, 실패 0개였다. 이 감사 전용 테스트 5개가 모두 통과했다. 최종 Preview 빌드는 정적 경로 1,467개를 모두 생성하고 READY가 되었다. [수정된 Preview 열기](https://blue-marina-40dnmw9fg-chiweon.vercel.app)
