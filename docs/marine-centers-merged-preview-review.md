## 앱 반영 가능 여부

조건부 가능입니다.

미리보기 CSV는 앱 반영 후보로 사용할 수 있습니다. 다만 실제 반영 전 다음 사항을 한 번 더 확인해야 합니다.

1. 병합된 name 표기가 사용자 화면에 너무 길지 않은지
2. 병합 id 네이밍이 앱 데이터 규칙에 맞는지
3. 필기시험장 `availableLicenses` 빈 값을 검색 필터에서 어떻게 처리할지
4. 같은 주소 + 다른 type 행을 UI에서 묶어 보여줄지
5. 주소 정규화 및 좌표 수집을 언제 진행할지
