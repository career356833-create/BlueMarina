# Blue Marina 출조업체 제휴 안내 · 파일럿 1페이지 원고

**Blue Marina**는 낚시 포인트, 어종, 바다 조건을 살펴보는 공개 정보 서비스입니다. 출조 영역은 업체가 직접 제공하고 확인한 선박·출항항·상품 정보를 소개하며, 고객 문의를 업체의 기존 전화 또는 공식 예약 페이지로 연결하는 방식을 준비하고 있습니다.

**어떻게 보이나요?** 관리자 검토와 게시 판단을 거친 정보에 한해 업체·선박·출항항, 상품명, 대상어종, 확인된 가격·일정, 공식 문의 경로를 안내할 수 있습니다. 현재 승인된 공개 출조상품은 없습니다. 실시간 잔여석, 예약 확정, 매출 성과는 제공하거나 보장하지 않습니다.

**무엇을 제출하나요?** 업체명과 공개할 연락처, 선박명, 출항항, 상품명, 대상어종, 확인된 가격·일정, 공식 홈페이지·예약 링크와 정보 출처입니다. 확인되지 않은 값은 비워 둡니다. 직접 입력 또는 CSV 템플릿으로 준비할 수 있습니다.

**절차:** 업체 제출 → 출처·신원·공개 동의·연락 경로 검토 → 관리자 승인 → 게시 후보 검토. 자동 게시나 자동 인증은 없습니다. 수정·게시 중단 요청은 운영 검토를 통해 처리합니다.

**파일럿 안내:** 운영 정책과 접수 백엔드가 준비된 범위에서 단계적으로 진행합니다. 고정 승인 기한, 영구 무료, 우선 노출은 약속하지 않습니다. 관심 있는 업체는 `/charters/partners`에서 안내와 템플릿을 확인할 수 있습니다. 별도 제휴 연락처는 현재 설정되지 않았습니다.
