# Blue Marina 출조업체 파일럿 제출 안내

## 준비 자료

업체명, 공개할 연락처, 선박명, 실제 출항항, 출조상품명, 대상어종, 확인된 가격·일정, 공식 홈페이지 또는 예약 링크와 정보 출처를 준비합니다. 가격·일정·잔여석을 확인할 수 없으면 비워 둡니다. 주민등록번호, 개인 집 주소, 비공개 승객 정보는 제출하지 않습니다.

## 제출 경로

- 직접 입력: `/charters/onboarding`에서 업체 → 선박 → 출항항 → 출조상품 → 일정·가격 → 검토 순으로 작성합니다.
- CSV: `/charters/partners/template.csv`를 내려받아 Excel 등에서 편집한 뒤 **CSV UTF-8**로 저장합니다. 기존 onboarding의 CSV 선택에서 먼저 로컬 dry-run을 확인합니다. 최대 1 MiB, 1,000행입니다. `VALID`은 자동 승인이나 게시를 뜻하지 않습니다.
- 기존 홈페이지: 공식 홈페이지의 해당 상품 URL을 `source_url`에 쓰고, 출처에서 확인할 수 있는 사실만 입력합니다. 웹사이트 URL만 제공했다고 상품이 자동으로 수집·게시되지 않습니다.

기존 CSV 파서는 `src/lib/charters/onboarding/csv-import.ts`의 전체 import 열을 요구합니다. 새 템플릿은 그 열을 모두 포함합니다. `business_name`과 `notes`는 **작성 보조 열**이며 현재 파서가 제출 payload에 보존하지 않습니다. 사업자 상호가 업체명과 다르면 운영 검토 때 별도 확인해야 합니다. 중요한 내용을 `notes`에만 적고 제출하지 마세요. 예시 행의 `DEMO_PLACEHOLDER`와 `example.invalid`는 실제 업체·상품이 아닙니다. 제출 전 삭제하고 실제 값으로 교체합니다.

전화번호는 업체가 공개를 허용한 연락처만 적습니다. `website_url`, `booking_url`, `source_url`은 `http://` 또는 `https://` URL만 허용합니다. `target_species`가 여러 개면 `|`로 구분합니다. 어종은 정확한 canonical 명칭 또는 승인 alias만 자동 연결되며, 불명확한 명칭은 검토 대상으로 남습니다. 가격은 숫자로, `price_unit`은 `1인` 등 실제 기준으로 작성합니다. 확정 일정이 없다면 `schedule_date`, 출·귀항 시간, 잔여석을 비워 둡니다. 어선 좌표를 임의로 만들거나 출항항 좌표를 낚시 포인트 좌표로 복사하지 않습니다.

## 검토·공개

제출은 로그인 및 활성화된 접수 백엔드가 있을 때만 서버로 전송됩니다. 현재 백엔드가 비활성화된 환경에서는 제출 실패가 표시될 수 있습니다. 제출 후 출처·업체 신원·공개 동의·연락 경로·선박 crosswalk·중복·중요 충돌을 관리자가 확인합니다. 승인 결과는 promotion **candidate**일 뿐, 공개 게시가 자동으로 이뤄지지 않습니다. 처리 기한은 아직 확정되지 않았습니다.

업체·상품 정보와 제공한 전화·공식 예약 링크의 공개 범위를 확인하고 동의한 경우에만 제출합니다. 게시 후에도 수정·게시 중단을 요청할 수 있습니다. 부정확하거나 충돌하는 내용은 검토 후 비노출될 수 있습니다. 현재 화면의 동의 확인은 클라이언트 단계의 파일럿 안내이며, 서버에 별도 동의 이력·서명 기록을 저장하는 기능은 없습니다. 관리자는 공개 전 공급자 승인 근거를 별도로 확인해야 합니다.
