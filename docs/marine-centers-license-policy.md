# Blue Marina MarineCenter.availableLicenses 정책

작성일: 2026-06-19

## 목적

`MarineCenter.availableLicenses`는 시험장·교육장·면제교육기관이 어떤 면허 유형과 연결되는지 표시하기 위한 필드입니다.

실제 시설 데이터를 병합할 때 일반조종면허와 요트조종면허 가능 여부를 일관되게 입력하기 위해 아래 기준을 사용합니다.

## 값 정의

```ts
availableLicenses?: ("general" | "yacht")[];
```

| 의미 | 입력값 | 화면 해석 |
| --- | --- | --- |
| 일반조종면허 가능 | `["general"]` | 일반조종면허 관련 시설 |
| 요트조종면허 가능 | `["yacht"]` | 요트조종면허 관련 시설 |
| 일반/요트 모두 가능 | `["general", "yacht"]` | 두 면허 모두 관련 시설 |
| 미확인 | `[]` 또는 필드 비움 | 공식 자료로 면허 구분 미확인 |

## 입력 기준

### 1. `["general"]`

아래 조건 중 하나가 공식 자료에서 확인될 때 입력합니다.

- 일반조종면허 실기시험장으로 표시된 경우
- 일반조종면허 면제교육기관으로 표시된 경우
- 시험장별 응시가능 시험에서 일반조종 1급 또는 2급만 확인되는 경우
- 공식 자료에 요트와 분리되어 일반조종 관련 시설로 명확히 구분된 경우

주의:

- 시설명에 `요트`라는 단어가 없다는 이유만으로 `general`로 추정하지 않습니다.
- 필기시험장은 면허 구분이 명확하지 않으면 빈 값으로 둡니다.

### 2. `["yacht"]`

아래 조건 중 하나가 공식 자료에서 확인될 때 입력합니다.

- 요트조종면허 실기시험장으로 표시된 경우
- 요트 면제교육기관으로 표시된 경우
- 시설명 또는 공식 분류에 `요트`가 명확히 표시된 경우
- 시험장별 응시가능 시험에서 요트조종면허만 확인되는 경우

주의:

- 해양, 마리나, 요트장 같은 장소 성격만 보고 `yacht`로 추정하지 않습니다.
- 공식 분류가 없으면 빈 값으로 둡니다.

### 3. `["general", "yacht"]`

아래 조건 중 하나가 공식 자료에서 확인될 때 입력합니다.

- 같은 시설이 일반조종면허와 요트조종면허 모두 가능한 곳으로 표시된 경우
- 같은 주소, 같은 전화번호, 같은 운영기관이 일반/요트 항목에 각각 등장하고 병합 정책상 하나의 시설로 관리하기로 결정한 경우
- 시험장별 응시가능 시험에서 일반조종과 요트조종이 모두 확인되는 경우

주의:

- 단순히 같은 지역에 있다는 이유로 병합하지 않습니다.
- 주소가 같더라도 전화번호, 운영기관, 시험 유형이 다르면 별도 행으로 유지할 수 있습니다.

### 4. `[]` 또는 필드 비움

공식 자료에서 면허 구분이 확인되지 않을 때 사용합니다.

예:

- 필기시험장 목록에 시설명, 주소, 전화번호만 있고 일반/요트 가능 여부가 표시되지 않은 경우
- 교육장 안내에는 교육장명만 있고 면허별 가능 여부가 표시되지 않은 경우
- 공식 자료마다 표현이 달라 교차 검증이 필요한 경우

원칙:

- 미확인 값은 추정하지 않습니다.
- CSV에서는 빈 값으로 둡니다.
- TypeScript 데이터 반영 시에는 `availableLicenses: []` 또는 필드 생략 중 하나를 선택해 일관되게 사용합니다.

## 공식 자료 우선순위

`availableLicenses` 입력 시 아래 순서로 신뢰합니다.

1. 시험장별 응시가능 시험 공식 안내
2. 전국 시험장 안내의 일반/요트 구분
3. 전국 교육장/면제교육기관 안내의 공식 분류
4. 시험 접수 또는 교육 접수 화면의 선택 가능 항목

비공식 블로그, 카페, 커뮤니티, 지도 리뷰, 개인 후기 자료는 사용하지 않습니다.

## 동일 기관이 여러 기능을 가질 경우

같은 기관이 여러 기능을 수행할 수 있습니다.

예:

- 실기시험장
- 수상안전교육장
- 면제교육기관
- 일반조종면허와 요트조종면허 모두 가능

처리 기준:

1. 기능이 다르면 기본적으로 별도 행을 유지합니다.
   - `type`이 다르면 별도 시설 행으로 관리합니다.
   - 예: 같은 주소라도 실기시험장과 수상안전교육장은 별도 행.

2. 같은 `type`이고 같은 주소·전화번호·운영기관이면 병합 후보로 봅니다.
   - 일반/요트만 다르면 `availableLicenses: ["general", "yacht"]` 병합을 검토합니다.

3. 병합 여부가 불확실하면 별도 행으로 유지하고 `note`에 `병합 검토 필요`를 기록합니다.

4. 병합 후에도 공식 자료에서 분리 운영이 확인되면 별도 행으로 되돌릴 수 있습니다.

## CSV 입력 규칙

CSV에서 `availableLicenses`는 아래처럼 입력합니다.

| 의미 | CSV 값 |
| --- | --- |
| 일반조종면허 | `general` |
| 요트조종면허 | `yacht` |
| 일반/요트 모두 | `general|yacht` |
| 미확인 | 빈 값 |

예:

```csv
id,name,type,region,city,address,phone,availableLicenses,sourceUrl,sourceCheckedAt,note,status
sample-general,일반 시험장,practical-test,서울,마포구,공식 주소,02-0000-0000,general,공식 URL,2026-06-19,,active
sample-yacht,요트 시험장,practical-test,부산,영도구,공식 주소,051-000-0000,yacht,공식 URL,2026-06-19,,active
sample-both,겸용 시험장,practical-test,경기,가평군,공식 주소,031-000-0000,general|yacht,공식 URL,2026-06-19,,active
sample-unknown,필기시험장,written-test,서울,영등포구,공식 주소,02-0000-0000,,공식 URL,2026-06-19,면허 구분 미확인,active
```

## 앱 반영 전 체크리스트

- [ ] `availableLicenses`가 공식 자료 기준인지 확인
- [ ] 추정으로 입력한 값이 없는지 확인
- [ ] 빈 값은 미확인 상태로 의도적으로 남긴 것인지 확인
- [ ] 같은 주소의 일반/요트 시설은 병합 여부를 검토
- [ ] 같은 주소라도 `type`이 다르면 별도 행 유지 여부 확인
- [ ] 병합 검토가 필요한 행은 `note`에 기록

## 결론

`availableLicenses`는 검색 필터와 면허별 사용자 경험에 직접 영향을 주는 필드입니다.

따라서 공식 자료로 확인된 경우에만 값을 입력하고, 불확실한 경우에는 빈 값으로 두는 것을 기본 원칙으로 합니다. 이후 CSV 병합 시 이 정책을 적용하면 필기시험장, 실기시험장, 수상안전교육장, 면제교육기관 데이터를 같은 기준으로 정리할 수 있습니다.
