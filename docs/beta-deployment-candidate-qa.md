# Blue Marina 베타 배포 후보 QA 요약

작성일: 2026-06-17

## 현재 상태

Blue Marina는 수상동력기구 조종면허 학습 포털 베타 배포 후보 상태입니다.

현재 앱은 기존 KidsAuto SaaS 구조에서 Blue Marina 조종면허 학습앱 구조로 전환되어 있습니다. 일반조종면허와 요트조종면허 문제은행을 분리 지원하며, 홈 랜딩, 문제풀이, 모의고사, 오답노트, 진도율, 학습분석, PWA/광고/정책 페이지, 포털 골격 페이지가 포함되어 있습니다.

- 진도율 화면
- 학습분석 리포트
- 취약 카테고리/태그 분석 구조

## QA 결과 요약

### 기능 QA

- 일반조종면허 시작 링크 정상
- 요트조종면허 시작 링크 정상
- 랜덤풀이 진입 정상
- 모의고사 진입 정상
- 오답노트 진입 정상
- 학습분석 진입 정상
- 일반/요트 localStorage key 분리 확인
- 모의고사 50문항 중복 없는 출제 확인
- 오답노트 저장/삭제 흐름 확인
- 분석 리포트 복습 링크 진입 확인

### 랜딩 시각 QA

- 모바일 390px 기준 첫 화면 브랜드 노출 확인
- 일반/요트 시작 버튼 첫 화면 노출 확인
- 하단 네비게이션이 시작 버튼을 가리지 않음
- 가로 스크롤 없음
- 데스크톱 1440px 기준 Hero, 기능 카드, 포털 카드 배치 확인
- 광고 placeholder가 콘텐츠를 과도하게 침범하지 않음

### 포털 골격 QA

- `/license-guide` 응답 확인
- `/exam-guide` 응답 확인
- `/safety-guide` 응답 확인
- `/license-issue` 응답 확인
- `/leisure-report` 응답 확인
- `/centers` 응답 확인
- `/official-links` 응답 확인
- 실제 제도 내용은 최소화하고 `준비중`, `공식 자료 확인 후 입력`, `공식사이트 확인` 구조로 처리

## 배포 전 필수 확인사항

- Vercel 환경에서 `npm run build` 성공 여부
- production URL에서 홈, 학습, 랜덤, 모의고사, 오답노트, 분석 페이지 클릭 확인
- PWA manifest 정상 로드 확인
- service worker가 production에서만 동작하는지 확인
- 모바일 Safari/Chrome에서 홈 화면 설치 가능 여부 확인
- AdSense 심사용 정책 페이지 접근 가능 여부 확인
- 공식 신청 URL은 검증 전까지 실제 외부 링크 연결 금지
- 시험 절차, 수수료, 응시자격 등 제도성 콘텐츠는 공식 자료 검증 후 입력
- 문제 데이터 저작권/출처 고지 필요 여부 확인
- 개인정보처리방침 문의 이메일 최신 상태 확인
