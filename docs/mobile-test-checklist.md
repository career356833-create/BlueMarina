# 모바일 실기기 테스트 체크리스트

## 기준 기기

- iPhone 14 Pro 기준으로 확인한다.
- Galaxy S20 기준으로 확인한다.
- 390px 모바일 폭 기준으로 확인한다.

## 레이아웃

- 가로 스크롤이 발생하지 않는다.
- 상단 헤더 텍스트가 잘리지 않거나 겹치지 않는다.
- 하단 네비게이션이 본문 버튼과 겹치지 않는다.
- 홈 화면의 주요 카드와 버튼이 첫 화면에서 자연스럽게 보인다.
- PC 화면에서는 가운데 정렬된 대시보드 형태를 유지한다.

## 문제풀이

- 문제 지문이 긴 경우 줄바꿈이 자연스럽고 가독성이 유지된다.
- 보기 버튼 터치 영역이 최소 48px 이상이다.
- 보기 텍스트가 긴 경우 버튼 밖으로 삐져나가지 않는다.
- 정답 선택 후 정답/오답 색상 구분이 명확하다.
- 해설이 긴 경우 페이지 스크롤로 끝까지 읽을 수 있다.
- 다음 문제 버튼이 하단 네비게이션에 가려지지 않는다.

## 모의고사

- 모의고사 50문항을 순서대로 이동할 수 있다.
- 각 문항의 답안 선택 상태가 결과 계산에 반영된다.
- 제출 후 점수와 1급/2급 합격 판정이 표시된다.
- 틀린 문제 목록이 결과 화면에서 확인된다.

## 오답노트

- 틀린 문제가 localStorage에 저장된다.
- 오답노트에서 문제를 다시 풀 수 있다.
- 맞힌 오답은 목록에서 제거된다.
- 삭제 버튼으로 오답을 수동 삭제할 수 있다.
- 오답이 없을 때 빈 상태 안내가 자연스럽다.

## 저장성

- 새로고침 후에도 localStorage의 진도율, 오답노트, 모의고사 기록이 유지된다.
- 브라우저를 닫았다가 다시 열어도 기존 기록이 유지된다.
- 오프라인 접속 시 기존에 로드된 앱에서 내장 문제 풀이가 가능한지 확인한다.

## PWA 가능성

- 홈 화면 설치 가능 여부를 점검한다.
- 앱 아이콘, manifest, theme color 추가 필요 여부를 확인한다.
- 오프라인 캐시 전략이 필요한지 확인한다.
